# Стоимость заявок

Новые заявки из корзины и формы консультации создаются без согласованной
стоимости: `orders.total` и `order_items.price` равны `NULL`. Ноль — отдельная,
явно указанная сумма, а не отсутствие цены. Каталог тарифов сохраняет цены «от».
При оформлении браузер отправляет только ID выбранных тарифов, сервер проверяет
их наличие и активность и сохраняет названия из БД без тарифных цен.

Администратор открывает «Заказы» → нужная заявка → «Согласованная стоимость, ₽».
Сумма задаётся в целых рублях. Пустое поле возвращает состояние «Стоимость не
согласована». `price_agreed_at` хранит момент последнего сохранения суммы в UTC.
Сохранение в админке не является подтверждением согласия клиента.
Повторная отправка той же заявки не перезаписывает согласованную сумму.

Перед публикацией этих изменений на другом сервере необходимо применить
`migrations/012_order_agreed_price.sql` штатным CLI-мигратором (`php migrate.php`).
Предварительно следует проверить остальные ожидающие миграции. Сама миграция 012
не удаляет записи и не меняет суммы прежних заявок. Исторические суммы остаются
видимыми в админке. Уведомления о заявках по-прежнему не содержат стоимости.

Проверки: `php tests/order-agreed-price.php`, `php tests/order-service-p0.php`
используют временные таблицы текущего подключения. Браузерная проверка
`node tests/quote-cart-browser.cjs` не отправляет формы и подменяет API чата
и согласия на аналитику.
