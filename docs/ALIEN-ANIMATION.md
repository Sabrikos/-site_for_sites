# Пришелец: текущий режим без слежения

По решению владельца от 02.11.2026 персонаж не реагирует на курсор.

Главная страница загружает только:
- assets/alien/idle-manifest.js — постер, моргание и приветствие;
- contact-alien.js — небольшой клиентский проигрыватель.

Персонаж иногда естественно моргает. Раз в20–35секунд он поворачивается к
камере и машет рукой. Первый жест появляется через10–16секунд после загрузки
персонажа. Используются цельные кадры Kling, без разрезанных конечностей,
подмены зрачков, IK, трекинга и обработки движений мыши.

Между покоем и роликами есть короткие входные и выходные переходы. При
скрытии вкладки или уходе блока за экран воспроизведение приостанавливается.
При prefers-reduced-motion остаётся неподвижная исходная поза. При ошибке
загрузки постера остаётся оригинальный PNG из разметки.

Проверки: node --check contact-alien.js;
node --test tests/contact-alien-idle.test.cjs; php -l home.php.

Сведения о трекинге сохранены в ALIEN-TRACKING-NOTES.md. Архив не подключён.
