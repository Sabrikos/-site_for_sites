# Консультант сайта: дерево решений

01.11.2026: консультация сайта переведена на кнопки без вызова внешнего LLM.
Цены/сроки активных тарифов читаются из БД, дополнительные направления — из
опубликованного списка на главной. Для индивидуального проекта и услуг без
цены используется «по договорённости». Условия оплаты/правок не придуманы.

В режиме bot сервер принимает только разрешённый choice и сохраняет его
каноническое название. Произвольный POST message не становится запросом к ИИ.
После human-запроса свободная переписка ведётся через сайт и защищённую админку.
Статусы, CSRF, ограничения частоты и проверка generation сохранены.

Telegram получает только постоянное сообщение:
«На сайте Vega Studio запросили специалиста. Откройте раздел чатов в админ-панели сайта.»
Нет текста пользователя, истории, идентификаторов диалога/заказа/посетителя,
контактов, параметризованных ссылок или callback-кнопок.
Запуск — только переход к ожиданию специалиста. Продолжение переписки, закрытие,
создание заявки и заказа не отправляют данные сайта в Telegram.
Старые Reply/callback-кнопки website-диалогов из Telegram отключены.
Уже доставленные ранее сообщения этот патч не удаляет.

TELEGRAM_BOT_TOKEN и TELEGRAM_SUPPORT_CHAT_ID остаются локальными настройками.
Пустой/невалидный токен или недоступность Telegram не мешает сохранению запроса.
Фактическая доставка уведомления в живую группу в этой задаче не проверялась.

Отдельный публичный Telegram-бот всё ещё является самостоятельным каналом
и работает по прежним правилам. Нельзя утверждать, что он перестал собирать данные.
Местоположение рабочего сервера/БД и окончательные документы оператора также
не подтверждены этим изменением. Политика обновлена в части сценария сайта,
но реквизиты и сроки хранения по-прежнему требуют заполнения владельцем.

Проверки: php tests/decision-tree.php (без БД/сети), php -l изменённых PHP,
node --check web-chat.js. UI проверен на изолированном fake API: услуга → тариф →
позвать специалиста, скрытие свободного ввода до handoff.
