# Отложенная идея: слежение за курсором

Статус: ОТКЛЮЧЕНО по прямому запросу владельца02.11.2026. Не включать обратно
без нового запроса. Текущий талисман только моргает и иногда машет в камеру.

## Что сохранить для возможного возвращения

1. Использовать цельные позы/кадры Kling. Вариант с разрезанной PNG-рукой,
двухкостной IK-сеткой и отдельными зрачками владелец отверг: видны швы и
неестественная рука. Не повторять этот подход.
2. При активном слежении нельзя принудительно возвращать голову в центр
при смене направления, каждые несколько секунд или при неподвижной мыши.
Неподвижный курсор остаётся объектом внимания.
3. Попытки захвата должны происходить только рядом, не при каждом входе,
с паузами. Цельные записанные позы дают ограниченную траекторию, не свободный
3D-риг. Нельзя обещать произвольное движение зрачков/кисти из цельного PNG.
4. Для непрерывного выбора направления нужен проверенный круг взгляда из
8направлений, калиброванные временные метки, кратчайшая угловая дуга и зона
покоя около центра головы. Закрытые глаза нельзя оставлять на удерживаемой
позе. Требуется честно проверить шов круга и не выдавать morph-артефакты за
завершённую плавную анимацию.

## Где наработки

- archive/alien-tracking/contact-alien.js — последний незавершённый игрок
  со слежением, включая черновые изменения кольцевой фазы.
- archive/alien-tracking/contact-alien-puppet.js и contact-alien-math.js —
  отвергнутый эксперимент с разрезанным персонажем, только для истории.
- archive/alien-tracking/tests/ — прежние тесты (не текущие проверки сайта).
- assets/alien/gaze-circle-raw.webp и gaze-lower-raw.webp — новые исходные
  кадры Kling верхней/нижней дуг. Не используются текущей страницей.
- scripts/alien-ring-seam.py — эксперимент стыковки головы. Не подключён;
  визуальное качество стыка не принято и требует новой проверки.
- assets/alien/manifest.js и motion.js — старые метаданные слежения/захвата,
  не подключены. Активен только idle-manifest.js.
