# Vega Studio

PHP/MySQL-сайт, тарифы, заявки, web-chat и Telegram-бот.

## Обновление существующей копии

После `git pull --ff-only origin main` сделайте резервную копию базы и выполните
`php migrate.php` из корня проекта (PHP должен быть доступен в PATH).
Миграции добавляют служебную таблицу ограничения отправок и поля заявок,
а также устанавливают цену тарифа «Индивидуальный проект» в 5 000 ₽.
Не импортируйте `database.sql` поверх рабочей базы: это файл первоначальной установки.
Локальные `.env` и `bd.php` сохраняйте со своими настройками; они не передаются через Git.

## Сроки согласий на аналитику

Миграции `007_analytics_consents.sql` и `008_analytics_retention.sql` создают журнал
и сроки хранения. Разрешение на аналитику действует 6 календарных месяцев.
Подтверждение хранится 12 календарных месяцев после отзыва, замены новым решением
или окончания разрешения. Отказы хранятся 12 месяцев с даты решения.
Повторная отправка одного запроса срок не продлевает.

Ежедневная очистка выполняется командой `php personal-data-maintenance.php` из корня
проекта. На Beget её нужно добавить в cron после размещения сайта, указав абсолютные
пути к PHP и файлу. Команда также выполняет существующую очистку заявок и чатов.
Добавление кода в репозиторий само по себе не создаёт задание cron.
Сроки хранения резервных копий согласуются отдельно при настройке хостинга.

[Реализация ассистента, результаты проверок и инструкции запуска](docs/ASSISTANT.md)

В инструкции отдельно описаны настройка OpenAI, уведомления двум администраторам и действия напарницы. Настоящие ключи хранятся только в локальном `.env`.
